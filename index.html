Desktop-Based Inventory Application for Keshia Store (2025)

Created for a 6th semester scientific paper using Java and MySQL.

Abstract: Keshia Store has been a retail store selling daily necessities since 2010. Until now, inventory data management at Keshia Store has been done manually, namely by recording incoming and outgoing goods using a notebook. Although this method seems quite practical, as the number of items and daily transactions increases, this method causes inefficiency and potential data errors. One solution that can overcome the challenges of manual stock management is to create a desktop-based inventory application. This application is built with the Java programming language, a MySQL database, and runs on the Windows operating system. The development method used is the System Development Life Cycle (SDLC). Test results show that this application is capable of managing master data, processing transactions, and generating accurate reports according to requirements. This application successfully improves the operational efficiency of Keshia Store by automating stock updates, accurate transaction recording, and providing real-time stock information, thus supporting better decision making.

Web-Based Indonesian Comic Catalog and Chatbot (2026)

Created as a final-year thesis project during the 8th semester, utilizing Retrieval-Augmented Generation and the Gemini AI model. Used Next.js as the project framework.

Abstract: The ease of access to Indonesian comics is often not matched by a flexible search system, as conventional search methods remain based on rigid keywords, and the direct use of Large Language Models (LLMs) risks generating information hallucinations. This research aims to design and build a web-based Indonesian comic catalog application integrated with a Retrieval-Augmented Generation (RAG)-based chatbot and the Gemini AI model to facilitate information retrieval and comic recommendations based on natural language queries. The system was developed using the Waterfall methodology with a dataset of 310 comics. The system architecture was built using the Next.js framework, Supabase (pgvector) as a relational and vector database, Cloudinary for media storage, and Gemini for embedding processing and text responses. Comic data was processed into combined_text and embeddings for semantic search during the retrieval process. System evaluation was conducted using Black Box Testing and User Acceptance Testing (UAT). Test results show that the RAG catalog and chatbot applications were successfully designed and function as intended. UAT testing on 37 respondents yielded an acceptance rate of 86.14%, with the highest scores in the areas of device accessibility (89.72%) and chatbot response comprehension (88.11%). Thus, the developed system has proven to be viable and well-received by users.
